# Sistema de Gestión de Solicitudes y PQRS
### Gases de Occidente S.A. E.S.P.

Proyecto desarrollado para la asignatura **Desarrollo de Aplicaciones Web**  
Corporación Universitaria Iberoamericana — 2026

---

## Tecnologías utilizadas

**Frontend**
- React 18
- React Router v6
- Context API + Hooks (useState, useEffect, useContext, useReducer)
- Axios

**Backend**
- Node.js + Express
- Swagger (OpenAPI 3.0)
- JWT para autenticación

---

## Estructura del proyecto

```
pqrs-gdo/
├── frontend/
│   └── src/
│       ├── components/     # Componentes reutilizables
│       ├── context/        # Context API (AuthContext)
│       ├── pages/          # Páginas de la aplicación
│       └── services/       # Axios + servicios de API
└── backend/
    └── src/
        └── routes/         # Rutas Express con documentación Swagger
```
